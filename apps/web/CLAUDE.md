## Animation

Use the **`motion`** package (npm: `motion`, the current official Motion library — not the deprecated `framer-motion` name) for any animation beyond simple CSS transitions: `import { motion, AnimatePresence } from "motion/react"`. Already a dependency here. Reach for the `animate` / `design-motion-principles` skills for *deciding* whether and how to animate (purpose, curve, duration, reduced-motion) before writing Motion code — see `DESIGN.md` Part F5 for this project's motion principles (comprehension/orientation only, `prefers-reduced-motion` is a first-class path, no decorative loops).
